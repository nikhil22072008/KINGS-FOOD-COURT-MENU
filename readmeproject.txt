# Kings Food Court

Kings Food Court is a simple Python project made for ordering food from a menu. The user can select food items, add them to the order, check the total amount and confirm the order.

## Features

- Shows food menu with prices
- Add food items to order
- View selected items
- Calculate total bill
- Checkout the order
- Exit the program

## How it works

When the program starts, it shows the food menu. The user enters the number of the item they want to order.

The selected food is added to the order. The user can then view the order and total price. At checkout, the program asks for confirmation.

## Python Concepts Used

- Classes and objects
- Lists
- Functions
- Loops
- if-else statements
- User input
- String formatting

## Classes

### OurItem
Used to store the name and price of a food item.

### Order
Used to manage the selected food items and calculate the total bill.

## How to Run

Save the code as `main.py` and run:

python main.py

Then follow the options shown on the screen.

## Menu Options

1-14 : Select food  
15 : View Order  
16 : Checkout  
17 : Exit

## Conclusion

This project helped in understanding how classes and objects can be used in a real-life example. It also uses basic Python concepts to create a simple food ordering system.
